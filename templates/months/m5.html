فيديوهات — State Variables
معادلات فضاء الحالة — ẋ=Ax+Bu و y=Cx+Du
State Space Equations — Full Derivation
فضاء الحالة يُصف النظام بمعادلتين: ẋ = Ax + Bu ومعادلة المخرج y = Cx + Du. المصفوفات A,B,C,D تحتوي كل معلومات النظام. هذا التمثيل يعمل مع الأنظمة MIMO وهو أساس نظرية التحكم الحديثة بالكامل.
State Vector x
يُلخّص ذاكرة النظام الكاملة — يكفي لتحديد سلوكه المستقبلي
A Matrix — الديناميك
تحكم في ديناميك النظام الداخلي — قيمها الذاتية = الأقطاب
B · C · D
B: المدخل للحالة · C: الحالة للمخرج · D: الربط المباشر
% بناء نموذج State Space
A=[0 1;-2 -3]; B=[0;1]; C=[1 0]; D=0;
sys = ss(A,B,C,D);
G = tf(sys) % تحويل لـ TF
eig(A) % القيم الذاتية = الأقطاب
💡

الخلاصة العملية: فضاء الحالة هو لغة MATLAB الطبيعية — كل دوال التحليل المتقدم تعتمد عليه. إتقانه يفتح أدوات التحكم الحديثة كاملة.

Neso
فيديوهات — Controllability
القابلية للتحكم والمراقبة — اختبار Kalman
Controllability & Observability — Kalman
القابلية للتحكم: هل يمكن نقل النظام من أي حالة لأي أخرى؟ اختبار Kalman: M = [B AB A²B...Aⁿ⁻¹B] رتبة n. القابلية للمراقبة: هل يمكن تحديد الحالة من المخرج؟ N = [C;CA;...CAⁿ⁻¹] رتبة n.
ctrb(A,B)
مصفوفة التحكم — rank = n يعني تحكم كامل بكل الحالات
obsv(A,C)
مصفوفة المراقبة — rank = n يعني يمكن تقدير كل الحالات
Preconditions
Controllable = يمكن تصميم متحكم · Observable = يمكن تصميم مراقب
rank(ctrb(A,B)) % يجب = n
rank(obsv(A,C)) % يجب = n

فيديوهات — Pole Placement
إرجاع الحالة ووضع الأقطاب — u = -Kx
State Feedback Pole Placement — Ackermann
المتحكم u = -Kx يُعيد الحالة للمتحكم مباشرة. اختيار K يضع أقطاب الحلقة المغلقة في المواضع المطلوبة. طريقة Ackermann أو place() في MATLAB تحسب K مباشرة من الأقطاب. الشرط: النظام قابل للتحكم.
u = -Kx
إرجاع كامل لمتجه الحالة — يُغيّر ديناميك النظام بالكامل
place(A,B,poles)
MATLAB يحسب K من الأقطاب المطلوبة مباشرة
Desired Poles
تُختار لتحقيق ζ وωn المطلوبين — مرتبطة بمواصفات الأداء
p_d = [-2+2i -2-2i];
K = place(A,B,p_d);
Acl = A - B*K;
eig(Acl) % تحقق من الأقطاب
step(ss(Acl,B,C,D)); grid on
💡

الخلاصة العملية: Pole Placement هو التحكم الدقيق — تختار الأقطاب بالضبط في مستوى S وتحسب K المقابل. أقوى من PID للأنظمة متعددة المتغيرات.

Neso
فيديوهات — LQR
Linear Quadratic Regulator — الكسب الأمثل تلقائياً
LQR — Optimal State Feedback Control
LQR يجد K الأمثل بتقليل J = ∫(xᵀQx + uᵀRu)dt. Q تحدد أهمية الأداء، R تحدد تكلفة جهد التحكم. MATLAB يحل معادلة Riccati تلقائياً بـ lqr(). الميزة: لا تحتاج اختيار الأقطاب — فقط Q وR.
Q — وزن الحالة
Q أكبر = استجابة أسرع + جهد تحكم أكبر
R — وزن التحكم
R أكبر = جهد تحكم أصغر + استجابة أبطأ
lqr(A,B,Q,R)
يحل Riccati ويُعطي K الأمثل فوراً
Q=[10 0;0 1]; R=1;
[K,S,e] = lqr(A,B,Q,R);
Acl = A-B*K;
step(ss(Acl,B,C,D)); grid on
% جرّب Q=[100 0;0 1] وقارن
💡

الخلاصة العملية: LQR الخيار الأذكى عند التردد في اختيار الأقطاب — يُوازن تلقائياً بين الأداء وجهد التحكم. الأكثر استخداماً في الطيران والروبوتات.

ما يملكه الفريق بعد الأسبوع الثامن عشر: تصميم متحكم إرجاع حالة كامل بطريقتين — Pole Placement الدقيقة وLQR الأمثل — مع التحقق ببرمجة MATLAB.

Neso
فيديوهات — Observer
مراقب Luenberger — التصميم ومبدأ الانفصال
Luenberger Observer — Design & Separation
معادلة المراقب: x̂̇ = Ax̂ + Bu + L(y - Cx̂). مصفوفة L تُحدد سرعة تقارب التقدير مع الحالة الحقيقية. يُصمَّم بـ place(A',C',p_obs)'. أقطاب المراقب يجب أن تكون أسرع 3-5 مرات من أقطاب المتحكم. مبدأ الانفصال: صمّمهما مستقلَّين ثم ادمجهما.
x̂ — تقدير الحالة
يُحسب من المراقب بدلاً من قياس x مباشرة — يُستخدم في u = -Kx̂
Observer Gain L
place(A',C',p_obs)' — ملاحظة الترانسبوز دائماً
Separation Principle
أقطاب النظام الكلي = أقطاب المتحكم + أقطاب المراقب مستقلَّين
% تصميم المراقب — 3-5x أسرع من K
p_obs = [-10+10i -10-10i];
L = place(A',C',p_obs)'; % ترانسبوز!
Aobs = A - L*C;
eig(Aobs) % تحقق من الأقطاب
💡

قاعدة الإبهام: أقطاب المراقب = 3-5 أضعاف بُعد أقطاب المتحكم عن الأصل. المراقب يجب أن يُتقن التقدير قبل أن يُستخدم في التحكم.

Hashim
Hashim — النظام المدمج
دمج المتحكم والمراقب — النظام الموسّع
Controller + Observer — Augmented System
Hashim يبني النظام الكامل: LQR + Observer مدمجان ومحاكاتهما ببرمجة MATLAB. يُظهر كيف يتقارب x̂ مع x ومدى تأثيره على أداء التحكم الكلي لنظام صناعي حقيقي.
% النظام الموسّع: متحكم + مراقب
A_aug=[A-B*K, B*K; zeros(size(A)), A-L*C];
B_aug=[B; zeros(size(B))];
C_aug=[C, zeros(size(C))];
sys_full=ss(A_aug,B_aug,C_aug,0);
step(sys_full); grid on

مشروع شهر ٥
محرك DC — State Space كامل ومقارنة PID
DC Motor — Full State Space Project
نفس محرك DC من شهر 3 لكن بأدوات فضاء الحالة: نمذجة SS، اختبار القابلية، تصميم LQR، تصميم Observer، دمجهما، ومقارنة مباشرة مع PID. هذه المقارنة توضح الفرق الجوهري بين التحكم الكلاسيكي والحديث.
% محرك DC — State Space
Ra=1;La=0.01;Km=0.01;J=0.01;Bf=0.001;
A=[-Ra/La -Km/La;Km/J -Bf/J];
B=[1/La;0]; C=[0 1]; D=0;
rank(ctrb(A,B)) % = 2 يعني قابل
[K]=lqr(A,B,diag([1 100]),0.01);
L=place(A',C',[-50 -60])';
% مقارنة مع PID
G=tf(ss(A,B,C,D));
Cpid=pid(5,2,0.5);
T_pid=feedback(Cpid*G,1);
T_lqr=ss(A-B*K,B,C,D);
figure; step(T_pid); hold on; step(T_lqr)
legend('PID شهر 3','LQR شهر 5')

الوثيقة النهائية: نمذجة SS، اختبار القابلية، تصميم LQR مع مختلف Q/R، تصميم Observer، النظام الموسّع، مقارنة مع PID بالرسومات والأرقام، والاستنتاج: متى تختار كلاً منهما.
